# Japan Trip Log

2026년 8월 일본 여행 일정 체크와 여행 기록을 위한 정적 웹앱입니다.

## 포함 기능

- 8월 11일-15일 날짜별 일정 체크
- 바텀 내비게이션 기반 일정/지도/기록/지출/준비 분리
- 일정 탭의 다음 일정 카드
- Google Maps 기반 장소 지도 탭
- 여행 노트 기록과 삭제
- 준비물 체크와 추가 준비물 입력
- 지출 입력, 총액, 식비, 교통비, 결제자 요약
- JSON 데이터 내보내기/가져오기
- GitHub Pages 배포 워크플로우

## 로컬 실행

브라우저에서 `index.html`을 열면 바로 사용할 수 있습니다.

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 이 프로젝트를 `main` 브랜치로 push합니다.
2. 저장소 `Settings > Pages`에서 Source를 `GitHub Actions`로 설정합니다.
3. `Actions` 탭의 Pages 배포가 끝나면 배포 URL이 생성됩니다.

기록 데이터는 각 브라우저의 로컬 저장소에 저장됩니다. 여러 사람이 같은 기록을 맞추려면 앱 안의 `데이터 내보내기`와 `데이터 가져오기`를 사용합니다.
